# Security and safety reporting

## Scope

This repository contains educational source code for a physical robot. Reports about unsafe default behavior, accidental motor activation, supply-chain concerns, exposed credentials, or other security issues are welcome.

## Reporting

Please use GitHub's private security-advisory/reporting feature for this repository when available. If private reporting is unavailable, open a minimal public issue **without** credentials, personal data, exploit details that increase physical risk, or instructions likely to cause unsafe movement.

Include:

- the affected commit or file;
- hardware and library versions, if known;
- a safe, reproducible description; and
- the observed and expected behavior.

Do not connect or operate hardware solely to reproduce a report. Keep wheels elevated and use the README's power-off procedure if a robot behaves unexpectedly.

## Supported versions

The default branch (`main`) is the only actively maintained version. Because this is an educational project with no hardware verification, fixes are evaluated on a best-effort basis and should not be treated as a safety certification.
